# Datasets

This project uses the **UK-DALE** (UK Domestic Appliance-Level Electricity) dataset for training and evaluating the Seq2Point NILM model referenced in ERS-2026-001.

The raw dataset file (`ukdale.h5`, several GB) is **not** committed to this repository — only its metadata is included. See [dataset_structure.md](dataset_structure.md) for what's included and [../docs/reproducibility.md](../docs/reproducibility.md) for how to obtain and place the dataset before running the workflow.
